# Procurement glossary

Plain explanations of terms found in the corpus. Add to this whenever a new term appears.

| Term | Meaning |
|---|---|
| Procuring Agency (PA) | The buyer. The government body running the tender. |
| Bidder / Consultant | A company competing for the contract. |
| Procurement notice / IFB / NIT | The short advertisement announcing a tender. Not the full document. |
| Bidding document / BSD | The full tender document: instructions, eligibility, evaluation, contract terms, forms. |
| RFP (Request for Proposal) | The full document for consultancy tenders, where quality matters as well as price. |
| TOR (Terms of Reference) | What the winning consultant must actually do. |
| BDS (Bid Data Sheet) | The tender-specific values that fill in the standard template: dates, amounts, criteria. Most factual answers come from here. |
| Corrigendum | An official correction to a published tender. Often extends the deadline; can change amounts, eligibility or scope. Overrides the original. |
| Addendum | An official addition or change to the bidding document. Treated like a corrigendum for "latest wins". |
| Revised bidding document | A reissued full document, often after a pre-bid meeting. |
| Pre-bid meeting / minutes | Session where bidders ask questions. The minutes are official clarifications. |
| Single stage two envelope | Technical and financial proposals submitted together but sealed separately. Technical is evaluated first; only passing bids get their price opened. |
| QCBS | Quality and Cost Based Selection. Winner chosen on combined technical and price score (for example 80/20). |
| Bid security | A deposit proving the bidder is serious. Forfeited if they withdraw. |
| Bid securing declaration | A signed promise used instead of a money deposit. |
| Performance guarantee | Deposit from the winner, held while the contract is delivered. |
| BOQ (Bill of Quantities) | Itemised list of work or goods with quantities, priced by bidders. |
| Bid validity | How long a submitted bid stays binding. |
| EPADS | Pakistan's e-procurement system for federal (and some provincial) tenders. |
